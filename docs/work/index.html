THE PROTOCOL

Claim, do, regenerate.

Built for many concurrent agents and humans. Every step is mechanical except the mathematics.

  1. Pick. python3 scripts/work.py --next 5 (or filter with --kind comparator), or browse below. Higher items are runnable and earlier in dispatch order.
  2. Claim. Search open issues for the item's claim title. If none is open, open one with the claim template (each item page has both links). The scope digest pins what you claimed.
  3. Do only the deliverable. Meet every acceptance line; respect the boundary. A different idea is a new item, not a wider PR.
  4. Regenerate. python3 scripts/regen.py rewrites every derived file in about three seconds. Merge conflicts in generated files never need a manual merge: take either side and regenerate.
  5. Verify and ship. python3 scripts/regen.py --check and the tests; reference the item id and close the claim with the PR.

Full agent protocol: AGENTS.md · 100-slot wave: SCALE.md · machine-readable queue: api/work.json.
