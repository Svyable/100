Exact Alperin weight counts via radical p-subgroups and character degrees

Hypothesis
For every finite group G and every prime p, the number of conjugacy classes of Alperin p-weights equals the number of simple modules of FG over an algebraically closed field of characteristic p.
First proof obligation
State a restricted family of blocks (for example a named defect-group isomorphism type outside the order-100 census) and prove or refute the weight count for that family.
Next executable step
Do not enlarge the named catalog inside order 100: that range is already covered by the 2007 computational verification. State a restricted family (for example blocks with a named defect-group isomorphism type) and a lemma outside that census.
What would falsify it
A finite group G and prime p for which the independently recomputed weight count differs from the number of p-regular conjugacy classes.
Current blocker
Every group of order at most 100 is already covered by published computational verification; a larger named catalog inside that bound is not a theorem.

Verified milestones

Reproductions of established mathematics test the machinery; they are not new theorems.

  • REPRODUCED KNOWN · 2026-10-31Alperin weight counts match p-regular class counts on named groups through A5

    For each listed group and each prime dividing its order, the number of radical-subgroup defect-zero weights equals the number of p-regular conjugacy classes. Smoke covers nine groups through D10; deep adds C5, C6, D12, S4 and A5. The checker rebuilds every count independently.

    Scope: Finite named catalog only; every case sits inside the published order-100 verification

    python3 scripts/lab.py --probe alperin
  • REPRODUCED KNOWN · 2026-11-01Alperin's weight conjecture l(G) = w(G) on 15 group-prime cases from S3 to PSL(2,7)

    For S3, A4, S4, A5, S5 and PSL(2,7) at every prime dividing the order, the number of p-regular classes equals the number of conjugacy classes of p-weights, counted over all p-radical subgroups with defect-zero degrees of N(Q)/Q from Dixon's modular method. The checker re-enumerates radical subgroups by a different criterion and recomputes degrees with a different prime. The deep run covers 46 cases, adding GL(2,3), A6, S6, PSL(2,8), PSL(2,11), PSL(2,13), A7, S7 and the Mathieu group M11.

    Scope: Known small range; not new
