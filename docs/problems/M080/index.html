Exhaustive grid search over GF(p)^n with GL-symmetry reduction

Hypothesis
Any n bases of an n-dimensional vector space can be arranged in an n x n grid whose rows are the given bases and whose columns are bases.
First proof obligation
Specify the next finite case not yet covered here (GF(2)^4) with an orbit-reduced instance count and a per-orbit certificate format.
Next executable step
Quotient instances by the stabiliser of the standard basis so that GF(2)^4 becomes exhaustive, storing one grid certificate per orbit.
What would falsify it
n bases of GF(p)^n with an exhaustive certificate that no valid grid exists.
Current blocker
GF(2)^4 has about 10^8 raw instances; orbit reduction under the stabiliser is not implemented yet.
