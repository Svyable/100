Proof campaign Benchmark reproduced

Interval-arithmetic argument principle and Hardy Z sign changes

Hypothesis
Every non-trivial zero of the Riemann zeta function has real part 1/2.
First proof obligation
A finite height is already classical. The next obligation is a zero-free statement with an explicit constant that does not follow from plugging this height into a known explicit formula, or a machine-checked count past the range a hand calculation can audit.
Next executable step
Raise the certified height by tightening the contour enclosures, then compare the isolating intervals against a published zero table entry by entry.
What would falsify it
A height T at which the certified argument count N(T) strictly exceeds the number of disjoint intervals where Z changes sign.
Current blocker
T = 36 is far below Platt–Trudgian (at least 3*10^12). Extending the height needs a faster contour, not a new idea about the hypothesis.
