FORMAL STATEMENTS

Say exactly what counts.

Formal statements are comparators: they pin down exactly what a proof or counterexample must establish. Core Lean 4 only, no Mathlib, no sorry; every kernel-checked theorem is also registered in data/lean_targets.json and axiom-audited by the Lean proof gate. Kernel-checked results include finite fidelity tests and explicitly scoped classical parametric identities; these are reproductions of known mathematics, not resolutions of the open statement.

WHY STATEMENTS FIRST

Comparators, then proofs.

A Lean-checked proof proves only what was encoded. So every target starts with an auditable statement, fidelity tests and an explicit list of what it does not cover.

01

Encode the registry statement

Core Lean 4, no Mathlib: every definition used is on the page, a few dozen lines, readable end to end.

02

Test the encoding

Fidelity examples are proved by the kernel: hand-checked cases must agree, degenerate objects must be rejected, and the axioms must be satisfiable.

03

Kernel-check finite instances

Witness tables from the exact probe lab are re-verified by the Lean kernel, a third check beside the lab's search and independent checker.

04

Audit external claims against it

A claimed proof elsewhere is compared with the comparator: same quantifiers, same objects, same exceptions — or the scope gap is recorded.

M071 · Combinatorics

Hadwiger conjecture

Every simple graph has a K_t minor (branch-set model, connectivity by no-split cuts) or a proper (t−1)-colouring.

/-- The registry statement. -/
def Statement : Prop :=
  ∀ (t n : Nat) (adj : Nat → Nat → Bool), IsGraph n adj →
    HasCliqueMinor n adj t ∨ Colourable n adj (t - 1)

M074 · Combinatorics

Caccetta–Häggkvist conjecture

Loopless digraph on n vertices, minimum out-degree ≥ r ≥ 1, has an injective directed cycle of length ≤ ⌈n/r⌉; StatementFor r fixes the out-degree slice.

/-- The registry statement. -/
def Statement : Prop :=
  ∀ (n r : Nat) (adj : Nat → Nat → Bool), 1 ≤ r →
    (∀ v, v < n → adj v v = false) →
    (∀ v, v < n → r ≤ outdeg n adj v) →
    ∃ ℓ c, ℓ ≤ (n + r - 1) / r ∧ IsCycle n adj ℓ c

M094 · Mathematical physics / finite structures

Hadamard matrix conjecture

For every k ≥ 1 an Int matrix of order 4k with ±1 entries and pairwise orthogonal rows.

/-- The registry statement. -/
def Statement : Prop :=
  ∀ k : Nat, 1 ≤ k → ∃ H : Nat → Nat → Int, IsHadamard (4 * k) H

✓ kernel-checked Explicit Hadamard matrices of orders 4, 8 (Sylvester) and 12 (Paley), re-checked by the kernel (order_4, order_8, order_12).

M075 · Combinatorics

Frankl union-closed sets conjecture

Families as bitmasks over ground set {0,…,k−1}; union-closed with a nonempty member implies some x with 2·deg(x) ≥ |F|.

/-- The registry statement, for every ground-set size `k`. -/
def Statement : Prop :=
  ∀ k F, F < 2 ^ (2 ^ k) → UnionClosed k F → HasNonemptyMember k F → Abundant k F

✓ kernel-checked Exhaustive over all 2, 16 and 256 families on ground sets of size 1, 2, 3 (ground_1, ground_2, ground_3).

M078 · Combinatorics

Graph reconstruction conjecture

Simple graphs on n ≥ 3 vertices with a deck-matching bijection σ (G − v ≅ H − σv) are isomorphic.

/-- The registry statement. -/
def Statement : Prop :=
  ∀ (n : Nat) (G H : Nat → Nat → Bool), 3 ≤ n → IsGraph n G → IsGraph n H →
    Hypomorphic n G H → Iso n G H

M096 · Mathematical physics / finite structures

Projective plane order 12

No incidence relation on 157 points and 157 lines with 13 points per line, unique joining lines and unique meeting points.

/-- The registry statement. -/
def Statement : Prop := ¬ ∃ I : Nat → Nat → Bool, IsPlane 12 I

✓ kernel-checked The axioms are satisfiable: planes of orders 2 (Fano) and 3 exist (exists_order_2, exists_order_3).

M095 · Mathematical physics / finite structures

Exact Ramsey number R(5,5)

Arrows n s t: every red/blue colouring of K_n has a red K_s or a blue K_t (cliques as vertex bitmasks). Conjecture: Arrows 43 5 5.

/-- The registry conjecture `R(5,5) = 43`, given the known lower bound. -/
def Conjecture : Prop := Arrows 43 5 5

✓ kernel-checked R(3,3) > 5: the pentagon colouring has no monochromatic triangle.

M019 · Arithmetic

Erdős–Straus conjecture

4/n = 1/x + 1/y + 1/z cleared to 4xyz = n(xy + yz + zx) with x, y, z > 0.

/-- The registry statement. -/
def Statement : Prop :=
  ∀ n : Nat, 2 ≤ n → ∃ x y z, Solves n x y z

✓ kernel-checked Explicit positive solutions for every 2 ≤ n ≤ 100, re-checked by the kernel.

✓ kernel-checked For every n with n % 4 = 3, positive denominators exist; n=4k+3 uses (k+1, 2n(k+1), 2n(k+1)), with no finite bound.

M006 · Number theory

Strong Goldbach conjecture

Every even n ≥ 4 is p + (n − p) with both prime; primes by trial division.

/-- The registry statement. -/
def Statement : Prop :=
  ∀ n : Nat, 4 ≤ n → n % 2 = 0 → ∃ p, p ≤ n ∧ IsPrime p ∧ IsPrime (n - p)

✓ kernel-checked The statement holds for every even 4 ≤ n ≤ 100 (least-prime witness table re-checked by the kernel; the lab covers far larger ranges in Python).

CONTRIBUTE

Add a statement.

The smallest useful contribution to an open problem is often an exact, reviewable statement.

  1. Add lean/Hundred/<Name>.lean with a header naming the problem id, a Statement, fidelity examples and, where possible, kernel-checked finite instances. Import it from lean/Hundred.lean.
  2. Add the entry to data/formalization.json (what it encodes, what it does not, kernel-checked declarations).
  3. Run python3 scripts/formal.py --check, cd lean && lake build and python3 scripts/build_site.py. CI repeats all three.
