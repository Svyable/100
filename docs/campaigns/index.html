M074 Caccetta–Häggkvist conjecture

Directed graph extremal search

Hypothesis
For each explicit pair (n,r), any loopless n-vertex digraph of minimum outdegree at least r contains a directed cycle of length at most ceil(n/r).
First proof obligation
Independently audit the public computer-assisted fixed-r=6 proof claim, including proof-to-CNF reductions, finite certificates and cited premises; distinguish restricted result from full CH.
Next step
Replay the external fixed-r=6 proof corpus on an independent host, verify its published hash and proof traces, and audit the hand-reduction steps before launching duplicate SAT search.
Falsifier
An explicitly checked digraph with min outdegree r and no directed cycle of length <=ceil(n/r).
Blocker
External fixed-r=6 proof corpus (438 MB) and independent specialist review have not been reproduced in this repo; neither encoding supplies a SAT/UNSAT certificate.
python3 scripts/digraph_orbits.py --n 5

M093 Linear MDS code main conjecture

Exhaustive arc search in projective spaces with frame-fixing symmetry reduction

Hypothesis
A linear [n,k] MDS code over GF(q) with k <= q has n <= q+1, except n = q+2 when q is even and k is 3 or q-1.
First proof obligation
Extend from k = 3 (Segre/Bose) to k = 4 arcs in PG(3,q) for small non-prime q (q = 8, 9), certifying maximum arc sizes.

Blocker

M094 Hadamard matrix conjecture

Algebraic constructions (Sylvester, Paley, Williamson) with exact orthogonality certificates

Hypothesis
A Hadamard matrix exists for every order divisible by 4.

Close the remaining engine gaps (116, 156, 172, ...) with symmetry-reduced Williamson and Goethals-Seidel constructions, then document the first order no implemented method reaches.

M041 Plane Jacobian conjecture

Exhaustive integer plane maps with inverses certified under Gabber's degree bound

Hypothesis
Every polynomial map C^2 -> C^2 with constant nonzero Jacobian determinant has a polynomial inverse.
First proof obligation
Reproduce the classical low-degree cases (Wang: degree <= 2; Moh: plane degree <= 100) on exhaustive integer classes, then isolate a structured family, such as maps with a prescribed Newton polygon, not covered by known degree bounds.
Next step
Enlarge the class to degree 4 with coefficients in {-1,0,1} using kernel enumeration per monomial support, and record the distribution of inverse degrees and of tame decompositions.
Falsifier
A plane map with exactly verified constant nonzero Jacobian and an exact proof (an infeasible linear system under Gabber's bound) that no inverse of degree <= deg F exists.
Blocker
Known results already cover plane maps of degree <= 100, so exhaustive small classes cannot reach new territory; novelty needs structural families.

M073 Sidorenko conjecture

Exact homomorphism-density search over certified host censuses

Hypothesis
For every bipartite graph H and every graph G, t(H,G) >= t(K2,G)^e(H).
First proof obligation
Confirm in current literature that K_{5,5} minus a Hamiltonian cycle is still the smallest open pattern, then fix a restricted host class (vertex-transitive graphs or small rational step graphons) where the inequality can be proved or exhausted.
Next step
Extend hosts from unweighted graphs to rational step graphons and run exact local search that minimises t(H,W)/t(K2,W)^15, replaying every candidate with the exact counter.
Falsifier
A host graph or rational step graphon W with exactly computed t(H,W) < t(K2,W)^e(H).
Blocker
Any counterexample is expected to need large or finely weighted hosts; unweighted hosts on at most 7 vertices give a minimum ratio of about 1.025 for the open pattern.

M006 Strong Goldbach conjecture

Verified-range certificates and least-partition statistics

Hypothesis
Every even integer n >= 4 is a sum of two primes.
First proof obligation
State a restricted, checkable lemma (for example an explicit bound on the least Goldbach prime in a named residue class or range) that is not already implied by the 4*10^18 verification or by the ternary Goldbach theorem.
Next step
