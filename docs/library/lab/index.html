Exact probe lab — computational reach of the 100

Generated by python3 scripts/lab.py from the ledger; do not edit by hand. Program as of 2026-10-31.

Every result below is a finite computation that a second, independent checker re-verified. Each range is either covered by known results or is a small exploratory falsifier check flagged in its probe's frontier. Nothing here is a new theorem, nothing resolves an open conjecture, and nothing can enter the Solved archive. The lab exists so that a new finite case, counterexample or certificate can be checked as soon as someone produces one, and so that each engine built for one problem is reused on the next.

Add a probe#

  1. Write scripts/probes/<name>.py with PROBE metadata, search(params), an independent check(params, result) that raises ProbeFailure, and scope(params). Reuse an engine if one fits.
  2. Register it in PROBES in scripts/probes/__init__.py.
  3. Add tamper tests in tests/test_lab.py: the checker must reject a corrupted certificate.
  4. Add or extend the problem's campaign and a reproduced_known milestone in data/research_program.json (verifier python3 scripts/lab.py --probe <id>).
  5. Run python3 scripts/lab.py, python3 scripts/lab.py --level deep, then the full rebuild in the README.
