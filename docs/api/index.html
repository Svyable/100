The 100/Data & API

DATA &amp; API

Take the data with you.

Everything on this site is static, versioned JSON and CSV regenerated from the validated ledgers on every change. No keys, no rate limits, no tracking.

ResourceWhat it contains
api/problems.jsonAll 100 problems in execution order with ranks, scores, readiness, evidence and modality.
api/problems/{id}.jsonOne problem with campaign, probes, milestones, roadmap, claim review, external claims and backlinks.
api/problems.csvSpreadsheet-friendly registry.
api/search.jsonThe compact index behind the / command palette.
data/portfolio.jsonThe complete legacy snapshot (lab, campaigns, milestones, solved archive).
feed.xmlAtom feed of milestones, claim reviews and program updates.

Example

curl -s https://svyable.github.io/100/api/problems/M071.json | python3 -m json.tool

The canonical sources are data/*.json in the repository; this API can never drift from them because CI rebuilds and byte-compares the whole site.
