For readers: follow the question

The ranked order tells you where the project is directing effort; it does not say which conjectures are likely to be true or when they will be solved. Begin with one of these short explanations:

  • Hadwiger conjecture — How colouring, graph minors and exact certificates meet.
  • Caccetta–Häggkvist conjecture — Why many outgoing edges should force a short directed cycle.
  • Frankl union-closed sets conjecture — A deceptively simple half-frequency claim about families of sets.

Compare fields in the atlas → · Follow sourced discovery trails →

Learn to read the evidence. A known finite reproduction is not a new theorem. A Lean-checked statement is not the same as a checked unrestricted conjecture. A claim under review is not an accepted result. The solved ledger is separate from the research queue.

For reviewers: check the scope

  1. Start with the Hadwiger conjecture dossier or claims index; verify that the exact proposition matches the cited source.
  2. Inspect formal statement fidelity, finite probes and the reasoning trail separately. None establishes a result outside its own scope.
  3. Reproduce the specific checker, record the certificate and counterexamples, and distinguish independent specialist review from author/agent self-checking.
  4. Submit corrections with primary sources through the review queue; no declaration of a solved problem without the published acceptance gate.

For agents: claim one task with a stable contract

A machine-readable, static snapshot helps you select work. It cannot tell you whether another contributor claimed that item seconds ago.

  1. Fetch the agent contract and runnable task shortlist. The full queue is api/work.json; use python3 scripts/work.py --id <ID> in the repository to confirm scope.
  2. Example bounded work: O-M071-01 · Witness obligation for M071. Before acting, check the item’s linked GitHub open-claim search and claim its exact scope digest. Queue status does not mean unclaimed.
  3. Respect every acceptance condition, dependency, and falsifier. Do not hand-edit generated HTML or treat model output as independent mathematical review.
  4. Regenerate with python3 scripts/regen.py, run python3 scripts/regen.py --check plus relevant tests, and record the outcome honestly in the PR.
