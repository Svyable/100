# Scale — proof-exchange wave

Generated by `python3 scripts/scale.py --write` (svyable.proof-exchange.v2); do not edit by hand.

100 parallel evidence-bound slots is an operating capacity target. It is not a claim that the portfolio yields 100 new theorems.

A filled slot is a claimable work packet with a scope digest. It is not a solved theorem, a readiness change, or a measured speedup.

## Operating readout

| Observable | Value | Boundary |
|---|---:|---|

| Cohort shapes touched (via jobs) | 30 / 30 | Shared attack templates |
| Derived work-queue size | 289 (283 runnable) | Source: `scripts/work.py` |
| Refused this wave | 6 | stop_range, externally blocked or dependency-blocked |
| Proof-obligation frontier | runnable=21, blocked=1, waiting=2, discharged=0 | Acceptance DAG only |

Slot mix: obligation=21, review=22, lean=9, job=42, roadmap=6

## How to take a slot

1. Search open issues for the packet's claim title.
2. If none is open, open `.github/ISSUE_TEMPLATE/claim.yml` with the scope digest.
3. Do only the deliverable; keep the boundary.
4. Prefer the scout / adversary / checker split inside the claim rather than three duplicate attempts.
5. Regenerate with `python3 scripts/regen.py` before shipping.

Full agent protocol: [AGENTS.md](AGENTS.md). Work queue: `python3 scripts/work.py --next 5`. Coverage ablation: `python3 scripts/scale.py --mode coverage --budget 5`.
