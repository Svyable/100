# Approach — leverage dispatch

Generated by `python3 scripts/approach.py` from [data/methods.json](data/methods.json); do not edit by hand.

Attack shapes and scheduling bonuses. A shape is not a theorem, not a claim that the case is open, and not a change to editorial scores or readiness.

Dispatch score = editorial score + readiness + an action bonus. The bonus is a scheduling weight. It is not evidence, not a probability, and it does not change readiness. A known benchmark still earns no novelty.

**30 shapes** cover all 100 problems. **45 jobs** (one action on one shape) replace a per-problem queue. **79 problems have no campaign**; each of them points at a shared shape instead of a private method. **3 recorded experiments are refused** because the campaign blocker already places that range inside known mathematics.

## Action bonuses

| Action | Bonus | What it schedules |
|---|---:|---|
| `replay_claim_witness` | +40 | The claim review asks for a finite object an independent checker can accept or reject. That check can retire the target. The bonus is a scheduling weight, not evidence. |
| `build_engine` | +18 | The problem is computable and has no verifier. The engine roadmap already names the one build that covers it. Extend a different probe instead of this build only after the engine exists. |
| `replay_published` | +12 | A published finite object sits past what this repository checks. Import that object onto an independent checker. A longer search inside a settled range is not this action. |
| `lock_restriction` | +10 | A campaign exists and is blocked because the restricted class is not fixed. A checker written before the class is fixed does not raise readiness. |
| `mine_structure` | +6 | Certificates already exist. The next product is an invariant table or a parametric identity, not a longer range inside mathematics the campaign blocker already cites. |
| `scope_audit` | +8 | A manuscript may already match or miss the registered statement. Read that comparison before opening a new attack. A review whose scope is a different statement adds +8. |
| `specify_shape` | +0 | No campaign yet. Write one restricted statement inside the cohort's shape. Do not invent a private method, and do not treat the shape as a theorem. |
| `stop_range` | -36 | The recorded experiment only lengthens a range the campaign blocker already places inside a cited theorem. Refuse it. The replacement step is the one that starts with 'Do not'. |

## Shapes

Each shape is a template for a restricted attack. Filling it in does not assert that the restriction is open, new, or true.

### `critical_zeros` — Certified zero counts

**Problems:** M001, M002, M009. **Engines:** `interval_arithmetic`.

Build one interval-arithmetic zero-count certificate and reuse it for every problem in this shape. For the Riemann Hypothesis and the Generalized Riemann Hypothesis the certificate must show there is no zero with real part greater than 1/2 and imaginary part at most an explicit height, by sign changes on the critical line plus a Turing bound. Pair correlation uses the same ordinates as a certified statistic up to that height and has no finite falsifier. A count inside a published verification is a reproduction, not a theorem.

**Certificate.** Interval enclosures, sign-change ordinates and the Turing bound, recomputed by an independent evaluator.

**Falsifier.** A zero whose real-part enclosure lies strictly above 1/2. Pair correlation is not finitely falsifiable.

### `effective_diophantine` — Explicit Diophantine certificates

**Problems:** M004, M006, M019, M020. **Engines:** `primes`.

State one explicit identity or inequality on a named class that a cited theorem or computation does not already settle. The class is a residue class, a radical range, or a Mahler-measure bound with a constant. Certify the identity by exact arithmetic. Extending a probe deeper into a published verification is not this attack.

**Certificate.** An exact integer or rational identity, re-expanded by an independent arithmetic checker.

**Falsifier.** One integer in the named class that violates the explicit inequality, or an identity that fails when substituted.

### `sieve_infinitude` — Explicit sieve gaps

**Problems:** M005, M007, M008, M012, M018. **Engines:** none yet.

Name one modulus, admissible tuple or polynomial that a cited sieve theorem does not already settle, and write the missing estimate. The missing piece is a level of distribution, a singular-series lower bound, or an exceptional modulus. Do not search for more small primes.

**Certificate.** A finite admissibility or singular-series check, plus a citation of the theorem that would apply if the missing estimate were proved. The citation is not the proof.

**Falsifier.** The named tuple is inadmissible, or the claimed singular series is zero.

### `galois_representations` — One field, two computations

**Problems:** M003, M010, M013, M015, M016, M017. **Engines:** none yet.

Pick one explicit number field or elliptic curve and one finite invariant the conjecture predicts, and compute it two ways. The invariant is an analytic rank against a Mordell-Weil rank, the image of a residual representation, a Leopoldt defect, or a Galois realization of one polynomial. A database lookup of a case the literature already lists is a reproduction.

**Certificate.** The curve or polynomial, its conductor, and both computations with enough intermediate data to recompute.

**Falsifier.** An explicit curve or field, inside the stated hypotheses, whose two invariants disagree.

### `exponential_fields` — Exponential-algebraic certificates
