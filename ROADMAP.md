# Roadmap — 100 mathematical grand challenges

Generated by `python3 scripts/roadmap.py` from [data/roadmap.json](data/roadmap.json); do not edit by hand. As of **2026-10-31**. Also on the [public dashboard](https://svyable.github.io/100/#roadmap).

**Mission.** Turn 100 grand challenges into a pipeline of independently checkable progress: exact verifiers, certified finite cases, audited claims and restricted lemmas, with no breakthrough declared by announcement.

> Planning document. A shipped item is infrastructure, a reproduction of known mathematics or an audit unless its evidence says otherwise. Nothing here changes data/solved.json.

## Updating

Edit [data/roadmap.json](data/roadmap.json) in the same PR that ships the work, move the item to `shipped`, then run `python3 scripts/roadmap.py` and `python3 scripts/build_site.py`. CI fails if either output is stale, if an evidence path is missing, or if a now/next item lacks exit criteria.
